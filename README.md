# ImenMoj UserHub

A Flutter application designed to demonstrate a modular, maintainable architecture
and clean separation of concerns for a user management feature.

This repository contains a structured Flutter project with focus on:
- Clean Architecture
- Feature-based modularization
- Testable and scalable code organization

## Features
- User login and authentication
- Profile management
- Simple navigation flow
- Modular domain and presentation layers

## Tech Stack
- Flutter
- Dart
- Provider / Riverpod (State Management)
- REST API integration
- Local storage (if implemented)
- Unit & widget testing basics
